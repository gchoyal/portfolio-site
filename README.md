## 🛠️ Deployment to GitHub (Step-by-Step)

### Step 1: Create a GitHub Personal Access Token (PAT)
GitHub requires a Personal Access Token instead of account passwords for pushing code:
1. Go to **[GitHub Settings -> Tokens](https://github.com/settings/tokens)**.
2. Click **Generate new token (classic)**, check epo scope, and copy your token.

### Step 2: Push to GitHub
Open your terminal in this directory and run:
`ash
git init
git add .
git commit -m Initial commit: Gaurav Choyal Web Design Portfolio
git branch -M main
git remote add origin https://<YOUR_GITHUB_TOKEN>@github.com/gchoyal/portfolio-site.git
git push -u origin main --force
`

### Step 3: Enable Free GitHub Pages Hosting
1. Go to your repository on GitHub: https://github.com/gchoyal/portfolio-site/settings/pages
2. Under **Build and deployment -> Source**, select **Deploy from a branch**.
3. Under Branch, select **main** and **/ (root)**, then click **Save**.
4. In ~60 seconds, your portfolio site will be live at:
   https://gchoyal.github.io/portfolio-site/
